# AI EasyCare - Healthcare & Medication Reminder Platform

## Overview
AI EasyCare is an intelligent healthcare support platform designed to assist patients, caregivers, and families in managing medication schedules effectively through smart reminders, caregiver monitoring, and AI-powered health assistance.

## Features
- 💊 Smart medication reminders and alarms
- 👨‍⚕️ Caregiver monitoring dashboard
- 🤖 AI health assistant chatbot
- 📋 Prescription management
- 🚨 Emergency alerts
- 📊 Medication history tracking

## Project Structure
```
AI-EasyCare/
├── backend/                    # Java Spring Boot Backend
├── frontend/                   # React Frontend
├── docker-compose.yml
├── README.md
└── .gitignore
```

## Tech Stack
- **Frontend**: React, HTML5, CSS3, Axios
- **Backend**: Java, Spring Boot, Spring Security, JPA
- **Database**: MySQL
- **AI Integration**: OpenAI API
- **DevOps**: Docker, Docker Compose

## Prerequisites
- Java 11+
- Node.js 14+
- MySQL 8.0+
- Docker & Docker Compose

## Getting Started

### Backend Setup
```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
